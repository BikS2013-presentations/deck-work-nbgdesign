Install the skill in Claude Code

# register the public marketplace once, then install the plugin
/plugin marketplace add BikS2013-coding-agents/nbg-design
/plugin install nbg-design@nbg-design
# later, to pick up a new release
/plugin marketplace update nbg-design
claude plugin update nbg-design@nbg-design

Marketplace: github.com/BikS2013-coding-agents/nbg-design. Node 18+ for the scripts; a Chromium-based browser only for screenshots and the PDF.
